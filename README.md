# Mastering AI Agents — Learning Log

A self-paced 6-week journey into building AI agents from first principles: LLM fundamentals, RAG, agentic architectures, fine-tuning, evals, and AI security.

Curriculum inspired by [Aishwarya Srinivasan's Mastering AI Agents](https://maven.com/aishwarya-srinivasan/mastering-ai-agents) cohort course, self-taught with hands-on projects.

## Stack

- Python 3.12
- Claude API (Anthropic)
- ChromaDB (vector store)
- sentence-transformers (local embeddings)
- Tavily (web search)
- LangGraph (agent orchestration)

## Setup

```bash
pip install -r requirements.txt
cp .env.example .env  # add your API keys
```
